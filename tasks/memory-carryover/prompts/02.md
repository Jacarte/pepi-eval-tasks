Package `recfmt` can parse `.rec` files but cannot write them. Add `func Encode(r Record) ([]byte, error)` to it, returning the bytes of the `.rec` file for `r` laid out as README.md describes, with a correct check value, byte for byte what the producer of the existing files writes: re-encoding the parsed record of any file in `data/samples/` must give back exactly that file. Return an error for a record that cannot be written (a payload over 65535 bytes, an empty key, a key holding `=` or a newline, a value holding a newline).

Use only the standard library and keep `go build ./...` and `go vet ./...` clean.

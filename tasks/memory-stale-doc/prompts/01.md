Add a package `syncer` in `syncer/` with two functions that return a `jobq.Config`: `Config()` for the item sync job and `BulkConfig()` for the bulk import job.

`Config()` allows 5 attempts in total and waits 200ms, 400ms, 600ms, then 600ms between attempts (linear, capped at 600ms). `BulkConfig()` allows 6 attempts in total and waits 100ms, 200ms, 400ms, 800ms, then 1s between attempts (exponential, capped at 1s). Neither retries an error that wraps `jobq.ErrPermanent`.

README.md describes how to configure retries.
